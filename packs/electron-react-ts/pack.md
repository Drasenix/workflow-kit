# Pack : electron-react-ts

> Seeds projet pour une application **Electron + React + TypeScript** (socle `electron-react-boilerplate`, webpack, Tailwind).
> Contenu de `agents/` copié vers `.agents/`. **Techno uniquement** : aucun métier, aucune entité.

## Périmètre

Application desktop Electron avec deux processus (main / renderer), React côté renderer, communication IPC typée, tests Jest.
