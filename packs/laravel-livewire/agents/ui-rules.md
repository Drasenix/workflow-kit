# Conventions UI (Blade / CSS)

> **Statut : DÉFAUT PACK** (non contractuel) — squelette ; le projet le remplace par une `DÉCISION PROJET` (UI : en `U0`).
>
> Le projet définit ses propres conventions UI au fil de ses premiers développements
> (design system, composants, formulaires, navigation). **Ne pas traiter ce squelette comme une règle acquise.**

## À définir par le projet

| Sujet | À décider |
|---|---|
| Design system | thème, couleurs, typographie, tokens |
| Composants UI | inventaire, nommage, API (props/slots), où vit le markup stylé |
| Formulaires | markup des champs, états (erreur / disabled), label + message d'erreur |
| Navigation / shell | layout, menus, fil d'Ariane |
| Modales / dropdowns | pattern retenu |
| Icônes | composant dédié ou SVG inline |
| Anti-patterns | à documenter une fois les choix faits |

> Une fois les décisions prises, remplacer l'en-tête `DÉFAUT PACK` par `DÉCISION PROJET`.
